# 雨课堂刷课助手

### 脚本使用：

点击进入要刷的**课程目录**页面（不是视频页面）点击开始刷课按钮即可自动运行，如有bug，底部有作者联系方式，可能需要大家的账号进行测试修复，如有需要可以加底部作者联系方式，感谢每一位为脚本做出贡献的用户。  
![课程目录](/images/image.png "课程目录")

点击 **[停止刷课]** 会结束当前刷课并还原脚本对页面/播放器的修改（倍速、静音、倍速/暂停拦截包装等；可在脚本设置中关闭还原）；停止状态会持久保存，即使重新加载页面也不会自动恢复刷课，需再次点击 **[开始刷课]** 才会重新启动。**[重新加载]** 仅刷新页面：刷课进行中会自动续跑，已停止时不会恢复。

### 视频倍速设置：

点击面板底部的 **[脚本设置]** 按钮可配置视频倍速相关选项：

+ **目标倍速**：自动播放视频时的倍速，范围 1-16（超出自动钳制），设为 1 即原速播放。
+ **速度按钮改写设速**（默认开）：改写播放器速度按钮并点击来设速。
+ **直设媒体倍速**（默认开）：直接给 video/audio 的 playbackRate 赋值（含按钮不可用时的兜底与倍速保活）。
+ **倍速保活**（默认开）：播放期间定时检测并恢复被页面重置的倍速。
+ **解除倍速限制：拦截倍速回写**（默认开）：包装媒体元素的 playbackRate，拦截雨课堂播放器把倍速回写为低值（含限速定时器的异步回写）；用户手动调速不受影响。

以上开关相互独立，可按需单独关闭；保存后在下一次接管媒体时生效（倍速拦截包装的还原在保存时即时生效）。

### 刷课流程设置：

+ **自动切换下一个任务点/切换界面**（默认开）：当前任务点完成后自动点击下一个任务点或跳转其它页面继续刷课；关闭后停留在当前页面（不再自动点击下一集/下一知识点、不再跳转目录页），由用户手动切换任务点后点击 **[开始刷课]** 继续，可避免切换页面后抓取失败的连环报错。
+ **停止刷课后还原修改**（默认开）：点击 **[停止刷课]** 时还原脚本对页面/播放器的修改（倍速、静音、倍速/暂停拦截包装、防切屏包装等）；关闭后保留这些修改，例如停止刷课后仍保持倍速播放。
